# Güvenlik Politikası (Security Policy)

## Desteklenen Sürümler

Aşağıdaki sürümler aktif olarak güvenlik güncellemeleri almaktadır:

| Sürüm | Destek Durumu |
| :--- | :--- |
| `0.1.x` | :white_check_mark: Destekleniyor |
| `< 0.1.0` | :x: Desteklenmiyor |

---

## Güvenlik Açığı Bildirimi

Bir güvenlik açığı keşfettiyseniz, lütfen bunu herkese açık bir Issue olarak bildirmek yerine doğrudan proje yöneticisine iletiniz:

* **E-posta / İletişim:** GitHub Security Advisory (Private Vulnerability Reporting) veya doğrudan depo sahibi.
* Lütfen açığın yeniden üretilmesini sağlayan adımları ve etki analizini detaylı olarak belirtiniz.
* Bildirilen açıklar 48 saat içinde değerlendirilir ve doğrulandıktan sonra düzeltme yaması yayınlanır.
